# C6：非交互、整体 deadline、写入许可与 trace（2026-11-04）

结论：C6 代码、回归、默认/human 全量测试和最终二进制验收已完成。C1–C5 改动保留，未提交、推送或发布。

## 行为合同与迁移

| 控制项 | 全局选项 | tool/workflow 的 context.execution | 行为 |
| --- | --- | --- | --- |
| 非交互 | `--non-interactive` | `non_interactive: true` | stdin 非 TTY 时自动启用；false 不能取消自动模式，与显式全局 true 冲突 |
| 整体期限 | `--timeout 30s` | `timeout: "30s"` | 正 Go duration 字符串，无整体默认值；与 profile 的单次 HTTP timeout_seconds 独立 |
| 写入许可 | `--allow-write` | `allow_write: true` | 默认拒绝 TLS 写入及未核实操作；显式全局 true 与 context false 冲突 |

这些选项支持命令前后的位置。raw 使用全局选项，没有新增 context 接口。全局 timeout 重复或 global/context 重复时，按 duration 比较；`1s` 与 `1000ms` 等值，不同值报错。数值型 context timeout、零值、负值、无效或溢出的 duration 均在业务请求前失败。

默认行为变更需要迁移现有自动化：

```bash
# 已复核查询与 dry-run 不需要写入许可。
volclog --non-interactive --timeout 30s tool exec project.describe-projects
volclog --dry-run tool exec project.create --input file://req.json

# 用户已要求的实际写操作须显式声明许可。
volclog --non-interactive --timeout 30s --allow-write tool exec project.create --input file://req.json
```

许可来自 C5 的逐操作已复核语义，而非 HTTP 方法或名称推断。已复核的 POST 检索不需要许可，未知 raw GET 也不能默认放行。检查覆盖共享 TLS 请求入口、tool、workflow、human 快捷命令和独立的 assistant 流式请求；拒绝时为 `permission/WritePermissionRequired`、`remoteOutcome=not_sent`，不先触发动态凭据获取。dry-run 可规划受保护操作，实际执行仍需许可。该闸门只约束 CLI 行为，不是 IAM 边界或服务端幂等保证。

trace 脱敏只接受 `on`、`true`、`1`、`yes`、`enabled`、`strict`、`default`，均归一为开启；off/false/0/no/disabled 和未知值明确返回 validation，不再接受后静默无效。规则同时用于全局选项、项目默认值和 context.trace.redact。`context.trace=false` 或 `{"enabled":false}` 会关闭全局 trace-dir；关闭捕获不等于取消脱敏。无效 context 不创建 trace 工件。

## 实现与边界

- `global.go`、`run_pipeline.go`、`invocation_controls.go`、`context.go`：解析并合并控制项，在发送前统一检查许可。`operationIsReviewedRead` 同时用于执行和快捷命令指引，避免 describe 推荐无法执行的写命令。
- `execution_deadline_c6.go`、`run.go`、`cmd/volclog/main.go`：增加 RunContext，按调用入口的 startedAt 建立同一绝对期限，后续应用 context 不重置或延长预算；传递父取消、SIGINT 和 SIGTERM，保留 SIGPIPE 的交付错误处理。
- `tool_exec.go`、`shortcut_execution_human.go`、`tlsapi/client.go` 及 doctor/upgrade/配置状态/流式调用：传递同一个 context。构造或签名后、HTTP 发送前取消为 not_sent；已进入 transport 后仍保守保留 unknown，不能因 timeout 就宣称写入未送达。
- `input_context_c6.go` 和相关参数解析入口：`--input -`、context stdin、raw body、ingest 数据及 human 文件参数读取响应取消。仅在 context.execution.timeout 配置期限时，也会先应用预算再读取请求 stdin。显式管道数据仍可使用，与禁止交互提示分开。
- `login.go`、`configure_sso.go`、`sso.go`、`interaction_c6.go` 和终端读取文件：非交互 Console login 预先选择 device code/no-browser，SSO 不自动打开浏览器；需要替换会话确认或从多个账号/角色选择时返回 `interaction_required/InteractionRequired`，提供可操作指引，不读无限期 stdin。单候选和显式账号/角色保留原行为，没有新增 force 参数或隐式确认。
- `operation_error_classify.go`：保留取消阶段证据；SSO 回滚失败等事务错误优先于内层“需要交互”，不掩盖缓存恢复故障。
- generator、catalog/lock、describe、帮助、快捷命令执行/过滤指引、中英文文档和内置技能同步。165 个操作、159 个公开 ID、请求 schema、恢复政策与官网链接均保持 C5 原值；仅更新共享控制 schema 和对应摘要。159 个公开摘要已刷新。

Darwin/Linux 使用既有 x/sys 的 TTY 检测和 40ms Poll 等待，避免改动原文件描述符 flags 或创建悬挂的读取 goroutine。Windows 对不支持 read deadline 的控制台返回 interaction_required，需要通过显式参数避开该提示。其他平台保守进入非交互模式。

期限是 context 的协作式取消，不是强制杀进程保证；已取得结果仍要交付，既有回滚和清理保留，包括 Console callback 的最长五秒清理。SSO 选择失败可先写 token 再恢复，配置不提交；client-registration 缓存可能保留。本批没有扩展原有认证事务边界。
